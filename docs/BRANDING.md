# Sentinel branding

The app display name is Sentinel. The original vector mark combines a segmented centurion crest, an angular helmet and a protective shield in white on near-black. Its geometry is designed for small launcher icons and the existing monochrome interface.

Android uses an adaptive launcher icon with an opaque background and a separate inset foreground. Pixel Launcher applies its circular mask; other launchers may use their configured rounded shape. A separate alpha-only monochrome mask supports themed icons. The mark is inset for safe cropping. No phone-wide theme settings are modified.

Sources: design/sentinel-mark.svg, design/sentinel-logo.svg, design/sentinel-icon-round.svg. Android resources are generated by tools/create_brand.py; the adaptive-icon declaration and branding values are under app/src/main/res. The PNG previews are design renders, not phone screenshots.

Version 0.2-preview / code 2 retains dev.titus.sentinel.preview so it updates the existing installation. The app header and launcher label read Sentinel. Demo-data labelling and disabled live controls remain in place.
